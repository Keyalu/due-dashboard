错题 018｜IPv4分片-片偏移8字节对齐与最大分片计算

📅 2026-09-20 · 知识点：IPv4分片-片偏移8字节对齐与最大分片计算
错误类型：概念不清状态：待复习章节：CN/网络层

一、题目原图

题目

【2018 题 47 · IPv4 分片】主机 192.168.1.1 向 192.168.1.208 发送一个总长度为 1500 B 的 IP 分组，分组首部长度为 20 B。路由器通过接口 F1 转发该 IP 分组时进行了分片（F1 方向 MTU=800 B）。若分片时尽可能分为最大片，则：
① 一个最大 IP 分片数据字段的字节数是多少？
② 至少需要分为几个分片？
③ 每个分片的片偏移量是多少？

核心结论

最大分片数据 = 776 B（不是 780 B！），分 2 片，片偏移分别为 0 和 97。坑在"片偏移量以 8 B 为单位、必须整除 8"，所以 780 要向下取到 8 的倍数 776。

计算过程

① 原始分组：总长 1500 B，首部 20 B → 数据 = 1480 B。

② MTU 约束：F1 接口 MTU = 800 B，即每个分片总长度 ≤ 800 B。
  分片数据 = 800 − 20 = 780 B。

③ 8 字节对齐（关键！）：片偏移字段以 8 B 为单位，所以每个分片的数据长度必须是 8 的倍数。
  780 ÷ 8 = 97.5 → 向下取整 97 → 最大数据 = 97 × 8 = 776 B。

④ 分片个数：1480 ÷ 776 = 1.9... → 需要 2 片。

⑤ 每片明细：
  片 1：数据 776 B，总长度 20+776 = 796 B，片偏移 = 0 / 8 = 0，MF=1
  片 2：数据 1480−776 = 704 B，总长度 20+704 = 724 B，片偏移 = 776 / 8 = 97，MF=0

我的错误过程

直接用 800−20 = 780 B 作为分片数据，得到：
  片 1：780 B，偏移 0；片 2：700 B，偏移 780/8 = 97.5 ← 错！偏移必须是整数
忘了片偏移量以 8 B 为单位，分片数据长度必须是 8 的倍数。

错误原因（核心）

IPv4 首部的片偏移字段是 13 位，单位是 8 字节（不是 1 字节）。这意味着每个分片的数据起始位置必须是 8 B 的整数倍，所以除最后一片外，每个分片的数据长度也必须是 8 B 的整数倍。

同类易错提醒

  1. 片偏移单位 = 8 B，不是 1 B。计算时先把数据长度除以 8 取整再乘 8。
  2. MF 位：除最后一片 MF=0，其余 MF=1；片偏移最后一片为 0 不代表"第一片"，代表"最后一片的偏移量"。
  3. 总长度包含首部：MTU 是对"整个 IP 分组（首部+数据）"的限制，不是只对数据。
  4. 分片只发生一次：路由器分片后，后续路由器不会再按更小 MTU 二次分片（IPv4 规定）。
