错题 001｜二阶常系数齐次线性微分方程

📅 2026-09-02 · 知识点：二阶常系数齐次线性微分方程
错误类型：概念不清状态：待复习章节：高数 / 微分方程

一、题目原图

题目：考虑微分方程 $y''(t) - 4y = 0$（红线批注处为错误步骤）

二、我的错误过程

$y''(t) = 4y$
$\Rightarrow y'(t) = 4yt + C_1$  ← 错！
$\Rightarrow y(t) = 2yt^2 + C_1t + C_2$  ← 错！

三、错误原因（核心）

把未知函数 $y(t)$ 当成了与 $t$ 无关的常数来积分。
  • 关键错误：$\int 4y\,dt \ne 4yt$，因为 $y$ 是 $t$ 的函数 $y(t)$，不是常数。
  • 只有右端是「明确的 $t$ 的函数」（如 $y''=4t$、$y''=4$）时，才能对两边直接逐次积分。
  • 右端含 $y$ 本身时，$y$ 正是要求解的未知量，直接积分会构成"要求 $y$ 得先知道 $y$"的循环，因此必须改用特征方程法。

四、正确解法

$y'' - 4y = 0$ 是二阶常系数齐次线性微分方程，标准解法——特征方程：

特征方程：$r^2 - 4 = 0$  $\Rightarrow$  $r = \pm 2$
通解：$y(t) = C_1 e^{2t} + C_2 e^{-2t}$

验证：

  • $y = e^{2t}$：$y' = 2e^{2t}$，$y'' = 4e^{2t}$，$y'' - 4y = 4e^{2t} - 4e^{2t} = 0$ ✓
  • $y = e^{-2t}$：$y' = -2e^{-2t}$，$y'' = 4e^{-2t}$，$y'' - 4y = 4e^{-2t} - 4e^{-2t} = 0$ ✓

五、同类易错提醒

  1. $y'' = 4y$ 与 $y'' = 4t$ 完全不同：前者右端是「函数本身」，后者右端是「自变量」。
  2. 判断能否"连积两次"：右端含 $y$（或 $y'$）→ 不可直接积分；右端只含 $t$ → 可以。
  3. 二阶常系数齐次一律走特征方程：$ay'' + by' + cy = 0$  $\Rightarrow$  $ar^2 + br + c = 0$。
