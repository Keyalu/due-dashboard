错题 019｜一阶线性ODE积分因子+旋转体体积

📅 2026-09-19 · 知识点：一阶线性ODE积分因子+旋转体体积
错误类型：方法选择状态：待复习章节：高数/微分方程

题目（2019 数二 第17题）

(I) 解 y' − xy = (1/2)x·ex²/2，y(1)=e；
(II) 区域 D = {(x,y) | 1≤x≤2, 0≤y≤y(x)}，求 D 绕 x 轴旋转体积。

考点

一阶线性微分方程（积分因子法）+ 旋转体体积。

核心方法

(I) P=−x，Q=(1/2)x·ex²/2，积分因子 μ = e−∫x dx = e−x²/2。
(y·μ)' = Q·μ = (1/2)x，
y·e−x²/2 = ¼x² + C。
代入 y(1)=e：e·e−½ = e½ = ¼ + C ⇒ C = e½ − ¼。
(II) V = π∫12 y²(x) dx，代入 y(x) 后用换元 u=x²/2 积分。

易错提醒

一阶线性方程直接套公式 y = e−∫P(∫Q·e∫Pdx + C)，别凑微分。旋转体体积是 π∫y²dx，不是 ∫y dx。
