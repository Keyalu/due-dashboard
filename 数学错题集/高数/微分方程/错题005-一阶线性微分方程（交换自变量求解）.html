错题 005｜一阶线性微分方程（交换自变量求解）

📅 2026-09-03 · 知识点：一阶线性微分方程（交换自变量求解）
错误类型：计算失误状态：待复习章节：高数/微分方程

一、题目原图

我的错误过程

令 $t = 2x - 3xy^2 - y^3$，写 $\frac{dx}{dy} = \frac{dx}{dt}\cdot\frac{dt}{dy} = \frac{dx}{dt}(2 - 3y^2)$ ← 这里就错了！
求 $\frac{dt}{dy}$ 时把 $x$ 当成了常数；实际上 $t$ 里 $x$ 是 $y$ 的函数，链式求导需完整展开。
一路推导到 $\frac{Cy^3}{2x-3xy^2-y^3} = e^{-1/y^2}$，与标答不等价。

错误原因（核心）——基本功问题！

错因是基本功问题：复合函数链式求导不熟练 + 对"何时换元、何时用标准式"的方法判断不足。
  • 基本功 1（链式求导漏项）：$t = 2x - 3xy^2 - y^3$ 中 $x = x(y)$，故 $\frac{dt}{dy} = 2\frac{dx}{dy} - 3y^2\frac{dx}{dy} - 6xy - 3y^2$，绝非简单的 $2 - 3y^2$——把 $x$ 当常数是典型错误。
  • 基本功 2（导数记号混乱）：写 $\frac{dx}{dy} = \frac{dx}{dt}\cdot\frac{dt}{dy}$ 后代入 $t$ 的表达式，链式关系没理清，记号混用，一步错步步错。
  • 方法判断：$t$ 同时含 $x(y)$ 与 $y$，换元链极其复杂；此类含交叉项的方程应交换自变量与因变量，化为 $x$ 关于 $y$ 的一阶线性方程，而不是硬套 $t$ 代换。

正确解法

1) 改写：$(2x-3xy^2-y^3)\frac{dy}{dx} + y^3 = 0 \Rightarrow \frac{dx}{dy} = -\frac{2x-3xy^2-y^3}{y^3} = 1 + \frac{3x}{y} - \frac{2x}{y^3}$
2) 化一阶线性：$\frac{dx}{dy} + (\frac{2}{y^3} - \frac{3}{y})x = 1$，其中 $P(y) = \frac{2-3y^2}{y^3}$，$Q(y) = 1$
3) 积分因子：$\mu = e^{\int P\,dy} = e^{-\frac{1}{y^2} - 3\ln y} = \frac{e^{-1/y^2}}{y^3}$
4) 套公式：$x\mu = \int Q\mu\,dy = \int\frac{e^{-1/y^2}}{y^3}\,dy$，令 $u = -\frac{1}{y^2}$ 得 $\frac12 e^{-1/y^2} + C$
5) 通解：$x = \frac{1}{2}y^3 + Cy^3 e^{1/y^2}$（即 $x = y^3(\frac12 + Ce^{1/y^2})$）

关键点

看到 $\frac{dy}{dx}$ 与 $x,y$ 交叉项混在一起、无法直接分离变量时，优先考虑交换自变量与因变量写成 $\frac{dx}{dy} + P(y)x = Q(y)$。换元前先检验求导链是否可控，绝不能把 $x$ 当常数。

同类易错提醒

  1. 复合/隐式求导：变量相互依赖时必须写全链式法则，$x$ 是 $y$ 的函数就不能当常数（基本功）。
  2. 一阶微分方程求解顺序：可分离 → 齐次 → 一阶线性（积分因子）→ 其他换元，不要一上来乱换元。
  3. 交换自变量后注意 $P(y)$ 的符号，积分因子 $\mu = e^{\int P\,dy}$ 别漏负号。
  4. 做完用回代验证通解是否满足原方程，别因"看着像"就收手。
