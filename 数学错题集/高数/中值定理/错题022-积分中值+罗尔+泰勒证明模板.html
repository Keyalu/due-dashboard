错题 022｜积分中值+罗尔+泰勒证明模板

📅 2026-09-19 · 知识点：积分中值+罗尔+泰勒证明模板
错误类型：方法选择状态：待复习章节：高数/中值定理

题目（2019 数二 第21题）

f 在 [0,1] 二阶可导，f(0)=0, f(1)=1, ∫01f(x)dx=1。证明：
(I) ∃ξ∈(0,1) 使 f'(ξ)=0；
(II) ∃η∈(0,1) 使 f''(η)<−2。

考点

罗尔定理 + 泰勒展开（证明题）。

核心方法

(I) 由积分中值定理，∃c∈(0,1) 使 f(c) = 1/(1−0)·∫01f = 1。
f(1)=f(c)=1，由罗尔定理，∃ξ∈(c,1)⊂(0,1) 使 f'(ξ)=0。
(II) 在 x=c 处展开泰勒：
f(0) = f(c) + f'(c)·(0−c) + ½f''(η1)c² = 0，
f(1) = f(c) + f'(c)·(1−c) + ½f''(η2)(1−c)² = 1。
结合 f(c)=1、f(0)=0、f(1)=1 解出 f'(c) 并推 f'' 符号。

易错提醒

证明题三步：① 积分中值找等值点 c（f(c)=1=f(1)）② 罗尔得 f'(ξ)=0 ③ 泰勒在中间点 c 展开到两端点。这是"积分条件+罗尔+泰勒"的标准模板。
