错题 007｜CRC循环冗余校验-生成多项式与检验码辨析

错误类型：概念不清状态：待复习章节：CN/数据链路层

一、题目原图

题目信息

408 计算机网络 · 数据链路层（差错控制 CRC 循环冗余校验）
接收方收到的二进制比特序列为 10110011010，双方采用的生成多项式为 $G(x)=x^4+x^3+1$。问：该序列在传输中是否出错？若未出错，发送数据的比特序列和 CRC 检验码的比特序列分别是什么？

我的错误过程

手写推导：
"由 $G(x)$ 知 CRC 检验码为 11001"　← 错！11001 是生成多项式的系数序列（除数），不是检验码
随后竖式做模 2 除法（10110011010 ÷ 11001），余数为 0，得出：发送数据 = 1011001，CRC 检验码 = 1010

错误原因（核心）

把"生成多项式"当成了"检验码"：$G(x)$ 的系数序列是除法中的除数；CRC 检验码是数据补 0 后除以 $G(x)$ 得到的余数（位数 = 多项式最高次）。
  • $G(x) = x^4+x^3+1 \Rightarrow$ 系数序列 11001（5 位，是"除数"）；最高次为 4 → 检验码固定 4 位。
  • 检验码不是凭空得到的：发送端把数据左移 4 位（补 4 个 0）除以 11001，余数才是 CRC 检验码。
  • 接收端验证：把收到的完整序列（数据+检验码）直接除以 11001，余数为 0 则无差错——本题余数 0000 ✓。
  • 除法的运算是模 2 除法（异或）：同 0 异 1、不借位，不是普通二进制除法。

正确解法

1) 生成多项式转除数：$G(x)=x^4+x^3+1 \Rightarrow 11001$，检验码位数 = 最高次 = 4 位
2) 接收端验证（直接除，不补 0）：
$\begin{array}{l} 10110011010 \div 11001 \text{（模 2 / 异或）}\\ \Rightarrow \text{余数 } 0000 \end{array}$　余 0 → 传输无差错 ✓
3) 拆分接收序列（数据 + 检验码）：10110011010 = 1011001（7 位数据）+ 1010（4 位检验码）
4) 反向验证（发送端视角）：数据 1011001 补 4 个 0 → 10110010000，÷ 11001 余 1010 → 发送序列 1011001+1010 = 10110011010 ✓ 与接收序列一致

验证：10110010000 除以 11001 的余数确实是 1010，拼接后恰好等于接收序列 → 全链路自洽。

同类易错提醒

  1. 生成多项式系数序列（如 11001）是除数；CRC 检验码是除法余数，位数 = 最高次（此处 4 位），二者别混。
  2. 模 2 除法 = 逐位异或：同 0 异 1、无借位无进位；商只在首位为 1 时取 1 并异或。
  3. 接收端验证：用收到的完整序列直接除以生成多项式，余 0 = 无差错（无需先拆数据/检验码）。
  4. 拼接顺序：发送序列 = 数据（左）+ 检验码（右），检验码来自数据补 0 后的余数。
