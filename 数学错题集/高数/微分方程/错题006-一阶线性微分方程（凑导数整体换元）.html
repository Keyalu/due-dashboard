错题 006｜一阶线性微分方程（凑导数整体换元）

📅 2026-09-03 · 知识点：一阶线性微分方程（凑导数整体换元）
错误类型：方法选择状态：待复习章节：高数/微分方程

一、题目原图

我的错误过程

看到 $y' = (x+1)\sec y - \tan y$ 无从下手：右端三角函数裹着 $y'$，既不能直接分离变量，也不知道该换什么。
没有识别出关键结构：$\sin y$ 的导数恰为 $y'\cos y$，两边同乘 $\cos y$ 即可凑出 $(\sin y)'$。

错误原因（核心）——没思路

错因：没思路——没有看出"凑 $(\sin y)'$"这条变形路径，卡在开头无从下手。
  • 没思路的根：缺乏"观察导数结构"的意识——看到 $\sec y$、$\tan y$ 应联想到 $\frac{d}{dx}\sin y = y'\cos y$，而 $\sec y = \frac{1}{\cos y}$ 正好能与之配对。
  • 突破点：方程两边同乘 $\cos y$，把 $y'\cos y$ 合并成 $(\sin y)'$，原方程瞬间变成关于 $\sin y$ 的一阶线性方程。
  • 处理技巧：右端含 $\sec y,\tan y$ 时先通分成 $\frac{x+1-\sin y}{\cos y}$，再同乘 $\cos y$ 消去分母。

正确解法

1) 通分：$y' = (x+1)\frac{1}{\cos y} - \frac{\sin y}{\cos y} = \frac{x+1-\sin y}{\cos y}$
2) 同乘 $\cos y$：$y'\cos y = x + 1 - \sin y$，即 $y'\cos y + \sin y = x+1$
3) 凑导数：$(\sin y)' + \sin y = x+1$（因为 $\frac{d}{dx}\sin y = y'\cos y$）
4) 换元：令 $t = \sin y$，得 $t' + t = x + 1$（一阶线性，$P=1,Q=x+1$）
5) 套公式：$t = e^{-\int dx}\big[\int(x+1)e^{\int dx}dx + C\big] = e^{-x}\big[\int(x+1)e^x dx + C\big] = e^{-x}(xe^x + C) = x + Ce^{-x}$
6) 回代：$\sin y = x + Ce^{-x}$（$C$ 为任意常数）

关键点（这道题怎么"有思路"）

看到 $y'$ 与 $\sin y/\cos y$ 纠缠：先想"谁的导数能凑出 $y'\cos y$？"→ 是 $\sin y$。于是两边同乘 $\cos y$ 凑出 $(\sin y)'$，整体换元降为一阶线性。这套"凑导数 + 整体换元"是处理含三角函数微分方程的通用思路。

同类易错提醒

  1. 见到 $y'\cdot f(y)$ 形式，先找"整体函数"：$\sin y$、$\cos y$、$e^y$、$y^n$ 等，其导数可能恰是方程里现成的组合。
  2. $\sec y$、$\tan y$ 先通分，再用 $\frac{1}{\cos y}$ 与 $y'\cos y$ 配对。
  3. 换元后务必回代变量（$t \to \sin y$），别把答案写成 $t$ 的形式。
