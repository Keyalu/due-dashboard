错题 008｜选择重传SR窗口尺寸约束与反例构造

📅 2026-09-09 · 知识点：选择重传SR窗口尺寸约束与反例构造
错误类型：概念不清状态：待复习章节：CN/数据链路层

一、题目原图

题目信息

408 计算机网络 · 数据链路层（流量控制与可靠传输机制 / SR 选择重传）
在选择重传协议中，设序号用 3 比特编号，发送窗口 $W_T=6$，接收窗口 $W_R=3$。试找出一种情况，使得在此情况下协议不能正确工作。

我的错误过程

初看无从下手，只写了约束公式 $W_T + W_R \le 2^3$ 和序号环 0-7-0，不知道反例该"怎么编"——卡在不知道从哪个场景切入构造协议失效的情况。

错误原因（核心）

SR 协议能否正常工作的判据是 $W_T + W_R \le 2^n$：不满足时，接收方"期待的新帧序号区间"与发送方"超时重传的旧帧序号区间"必然重叠，收到重叠序号的帧无法区分新旧 → 协议失效。
  • 本题 $W_T+W_R = 6+3 = 9 > 2^3 = 8$，不满足约束 → 必然存在失效场景，反例一定找得到。
  • 重叠的本质：发送方重传旧帧区间 $[0, W_T-1]$，接收方期待新帧区间 $[W_T, (W_T+W_R-1) \bmod 2^n]$；两区间重叠当且仅当 $W_T+W_R > 2^n$，重叠长度 $= W_T+W_R-2^n$。
  • 本题重叠长度 $= 9-8 = 1$，重叠序号 = 0（接收方期待 6、7、0，与重传的 0 号帧冲突）。

正确解法（含反例）

1) 检查约束：$W_T+W_R = 9 > 8$ → SR 无法正常工作。
2) 构造反例（标准剧本）：
　· 发送方发满 $W_T=6$ 帧：0 1 2 3 4 5，发送窗口满，暂停；
　· 接收方收到全部 6 帧，逐帧确认，期待下一批 6 7 0（$W_R=3$）；
　· 假设所有确认帧都丢失，发送方超时，重传旧帧 0 1 2 3 4 5；
　· 接收方收到 0 号帧：它期待的"新 0 号"与重传的"旧 0 号"无法区分 → 协议不能正确工作。✓

验证：若约束满足（如 $W_T=W_R=3$，$3+3=6 \le 8$），接收方期待区间 [3,5] 与重传区间 [0,2] 不重叠，任何序号的帧都可唯一区分 → 协议正常。

举反例的通用技巧（记这一套）

第一步 · 判死：先算 $W_T+W_R$ 与 $2^n$。若 $>$ 则必失效，反例必存在；若 $\le$ 则协议正常，无需找反例。
第二步 · 套剧本（四幕剧，确认帧全丢）：
　① 发送方发满 $W_T$ 帧（$0 \sim W_T-1$），窗口满暂停；
　② 接收方全部收到并全部确认，期待窗口前移到 $W_T \sim (W_T+W_R-1) \bmod 2^n$；
　③ 所有确认帧全部丢失，发送方超时重传 $0 \sim W_T-1$；
　④ 指出重叠序号：两个区间交集中的帧，接收方无法判断新旧 → 协议失效。
第三步 · 点重叠：重叠长度 $= W_T+W_R-2^n$，重叠序号从 $(W_T+W_R-1) \bmod 2^n$ 往回数或直接列出两边区间找交集；叙述时把那个序号的"新/旧歧义"写清楚即可满分。

同类易错提醒

  1. SR 约束：$W_T+W_R \le 2^n$；GBN 约束：$W_T \le 2^n-1$——别混用（GBN 只看发送窗）。
  2. 若题设注明 SR 中 $W_T = W_R$，则 $W_T \le 2^{n-1}$（如 n=3 时最多 4）。
  3. 反例剧本必须包含"确认帧全部丢失"这一环——没有丢失就没有重传，没有重传就没有新旧重叠。
  4. 序号区间都要对 $2^n$ 取模（3bit → 0~7 循环）。
