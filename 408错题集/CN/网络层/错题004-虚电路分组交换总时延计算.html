错题 004｜虚电路分组交换总时延计算

📅 2026-09-07 · 知识点：虚电路分组交换总时延计算
错误类型：概念不清状态：待复习章节：CN/网络层

一、题目原图

题目信息

王道计网习题（虚电路分组交换）
一个分组交换网采用虚电路方式转发分组，分组首部和数据部分分别为 $h$ 位和 $p$ 位。现有 $L$（$L \gg p$ 且 $L$ 为 $p$ 的倍数）位报文要通过该网络传送，源点到终点之间线路数为 $k$，每条线路传播时延 $d$ 秒，数据传输速率 $b$ 位/秒，虚电路建立连接时间 $s$ 秒，每个中间结点平均处理时延 $m$ 秒。求源点开始发送数据直至终点收到全部数据所需的时间。

我的错误过程

$t_{总} = t_{建立} + t_{传输} + t_{传播} + t_{处理}$
$= s + (L/p)(h+p)/b + (h+p)/b \cdot (k-1) + kd + (k-1)m$
$\xrightarrow{\text{合并}} s + (k + L/p)(h+p)/b + kd + (k-1)m$　← 错！合并时把 $(k-1)$ 当成了 $k$，多算一跳 $(h+p)/b$

错误原因（核心）

虚电路分组交换的"流水线"时延模型没理清：$k$ 条线路、$k-1$ 个中间结点，转发跳数是 $k-1$ 而不是 $k$。
  • $k$ 条线路 → 中间结点有 $k-1$ 个（首尾是源点/终点，不算中间结点）。
  • 传输时延分两部分：源点发送全部 $L/p$ 个分组 = $(L/p)(h+p)/b$；最后一组经后续 $k-1$ 个中间结点逐跳转发（流水线，与源点发送重叠）= $(k-1)(h+p)/b$。
  • 正确合并：$(L/p + k - 1)(h+p)/b$，不是 $(L/p + k)(h+p)/b$——多算的一跳正是把 $k-1$ 误写成 $k$。
  • 传播时延是 线路数 $\times d$ = $kd$；处理时延是 中间结点数 $\times m$ = $(k-1)m$——两者用数对象不同，别混。

正确解法

$T = t_{建立} + t_{传输} + t_{传播} + t_{处理}$
1) 建立虚电路：$s$
2) 传输时延：源点发送 $(L/p)$ 组：$\dfrac{L}{p}\cdot\dfrac{h+p}{b}$；后续 $k-1$ 个中间结点转发（流水线）：$(k-1)\cdot\dfrac{h+p}{b}$
$\Rightarrow t_{传输} = \left(\dfrac{L}{p} + k - 1\right)\dfrac{h+p}{b}$
3) 传播时延：$k$ 条线路每条 $d$ → $kd$
4) 处理时延：$k-1$ 个中间结点每个 $m$ → $(k-1)m$

总时延：$T = s + \left(\dfrac{L}{p} + k - 1\right)\dfrac{h+p}{b} + kd + (k-1)m$

验证：取 $k=1$（源点终点直连，无中间结点）时，$T = s + (L/p)(h+p)/b + d$ ✓——只剩建立、发送、一条链路传播，公式退化为正确边界。

同类易错提醒

  1. 中间结点数 = $k-1$（$k$ 条线路夹 $k-1$ 个结点），转发跳数同理。
  2. 传输时延是流水线：源点发完 $(L/p)$ 组后，只有最后一组还欠 $k-1$ 跳，不是 $k$ 跳。
  3. 传播时延看线路数（$kd$），处理时延看中间结点数（$(k-1)m$）——用数对象不同。
  4. 合并时注意括号：$(L/p) + (k-1) = L/p + k - 1$，别把减 1 丢掉。
