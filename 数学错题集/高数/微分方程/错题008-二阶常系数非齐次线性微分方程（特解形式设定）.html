错题 008｜二阶常系数非齐次线性微分方程（特解形式设定）

📅 2026-09-07 · 知识点：二阶常系数非齐次线性微分方程（特解形式设定）
错误类型：概念不清状态：待复习章节：高数/微分方程

一、题目原图

二、题目

19.【P103】求微分方程 $y'' - 2y' + y = 2(3x^2 - 2)e^x$ 的通解。

三、我的错误

设特解时写成：$y^* = e^x (Ax^2 + B) \cdot x^2 = e^x (Ax^4 + Bx^2)$
❌ 漏掉了 $x$ 的一次项 $Bx$ 和常数项 $C$

四、正确解法

特征方程：$r^2 - 2r + 1 = 0 \Rightarrow r_1 = r_2 = 1$（二重特征根）
齐次通解：$\overline{y} = (C_1 + C_2 x)e^x$

右边 $f(x) = (6x^2 - 4)e^x$，$P_m(x) = 6x^2 - 4$ 是二次多项式，且 $\lambda = 1$ 是二重根 → 特解必须乘 $x^2$，待定多项式必须写成完整的二次式：
$$y^* = x^2 \cdot (Ax^2 + Bx + C) e^x = (Ax^4 + Bx^3 + Cx^2)e^x$$

五、关键技巧：$y = e^{\lambda x}u(x)$ 代入简化

若 $y = e^{\lambda x}u(x)$ 且 $\lambda$ 是二重特征根，则 $y'' - 2y' + y = e^{\lambda x} \cdot u''(x)$，无需暴力求二阶导。
令 $u(x) = Ax^4 + Bx^3 + Cx^2$，则 $u'' = 12Ax^2 + 6Bx + 2C$
代入：$e^x \cdot u'' = e^x (6x^2 - 4) \Rightarrow 12Ax^2 + 6Bx + 2C = 6x^2 - 4$
对比系数：$12A = 6,\ 6B = 0,\ 2C = -4 \Rightarrow A = \frac{1}{2},\ B = 0,\ C = -2$

特解：$y^* = e^x \left(\frac{1}{2}x^4 - 2x^2\right)$（本题恰好 $B = 0$，但设的时候不能省略）

六、最终答案

$$y = (C_1 + C_2 x)e^x + \left(\frac{1}{2}x^4 - 2x^2\right)e^x$$

七、错因复盘

归因：粗心大意 + 基础不牢
① 基础不牢：特解形式设定规则不熟——$\lambda$ 是几重根决定乘几个 $x$，$P_m(x)$ 是几阶多项式就设几阶完整待定式 $Ax^2 + Bx + C$，不能主观省略低次项（哪怕算出来是 0，书写时必须保留参与计算）；
② 粗心大意：本题最后结果碰巧对，但设特解步骤不严谨，考试中属步骤瑕疵，换其他题会直接算错。
