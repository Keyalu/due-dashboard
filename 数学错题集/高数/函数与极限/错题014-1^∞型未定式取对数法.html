错题 014｜1^∞型未定式取对数法

📅 2026-09-19 · 知识点：1^∞型未定式取对数法
错误类型：计算失误状态：待复习章节：高数/函数与极限

题目（2019 数二 第9题）

求 limx→0 (x + 2x)2/x。

考点

1^∞ 型未定式（"取对数+洛必达/重要极限"）。

核心方法

记 A = (x+2ˣ)^(2/x)，取 ln：
ln A = (2/x)·ln(x+2ˣ)。
x→0 时 x+2ˣ → 0+1 = 1，ln→0，用洛必达：
ln(x+2ˣ) ≈ (x + 2ˣ·ln2·x)/(1) ... 直接展开更稳：
x+2ˣ = 1 + x + (ln2)x + o(x) = 1 + (1+ln2)x + o(x)。
ln(1+(1+ln2)x) ~ (1+ln2)x。
故 ln A → 2(1+ln2)，A → e2(1+ln2) = 4e²。

易错提醒

1^∞ 型一律"取对数"，别直接用 lim(1+u)^(1/u)=e 硬套。注意 2ˣ 在 x=0 处展开是 1+(ln2)x+...，不是 1。
