错题 004｜齐次微分方程（切线法线截距应用题）

📅 2026-09-03 · 知识点：齐次微分方程（切线法线截距应用题）
错误类型：计算失误状态：待复习章节：高数/微分方程

一、题目原图

我的错误过程

分离变量后得到：$\frac{(3t+1)\,dt}{-3-3t^2} = \frac{dx}{x}$
下一步却写成：$\frac{1}{3}\int\frac{3t+1}{1+t^2}\,dt = \int\frac{dx}{x}$ ← 负号丢了！
实际：$\frac{3t+1}{-3-3t^2} = -\frac{1}{3}\cdot\frac{3t+1}{1+t^2}$，应为 $\frac{1}{3}\int\frac{3t+1}{1+t^2}\,dt = -\int\frac{dx}{x}$

错误原因（核心）

分离变量提公因式时把分母 $-3-3t^2$ 的负号弄丢了；后续又因符号错误，把含变量的 $\ln x^2$ 项不当并入常数 $C$。两个错误恰好"抵消"，最终答案碰巧正确——但方法有隐患。
  • 错误 1（漏负号）：提出 $\frac13$ 时负号必须留在外面：$\frac{3t+1}{-3-3t^2} = -\frac13\cdot\frac{3t+1}{1+t^2}$。
  • 错误 2（常数吸收不严谨）：正确路径中，代回 $t=\frac{y}{x}$ 后 $-\ln|x|$ 与 $+\ln|x|$ 两边抵消；因漏负号右侧变成 $+\ln|x|$，残留的 $\ln x^2$ 是含变量项，不能并入常数 $C$。
  • 结果：答案 $\ln\sqrt{x^2+y^2} + \frac13\arctan\frac{y}{x} = C$ 碰巧与标准答案一致，但若题目给出初值条件求特解，就会露馅。

正确解法

1) 列截距方程：切线纵截距 $y - xy'$、法线横截距 $x + yy'$，由比值 3:1 得 $y - xy' = 3(x + yy')$
2) 化简：$(3y + x)y' = y - 3x \Rightarrow \dfrac{dy}{dx} = \dfrac{y - 3x}{3y + x}$
3) 齐次化：令 $t = \dfrac{y}{x}$，$\dfrac{dy}{dx} = t + x\dfrac{dt}{dx}$，得 $x\dfrac{dt}{dx} = \dfrac{t-3}{3t+1} - t = -\dfrac{3(1+t^2)}{3t+1}$
4) 分离变量（注意负号！）：$\dfrac{1}{3}\int\dfrac{3t+1}{1+t^2}\,dt = -\int\dfrac{dx}{x}$
5) 积分：$\dfrac{1}{2}\ln(1+t^2) + \dfrac{1}{3}\arctan t = -\ln|x| + C$
6) 代回 $t = \frac{y}{x}$：$\frac12\ln\frac{x^2+y^2}{x^2} + \frac13\arctan\frac{y}{x} = -\ln|x| + C$，即 $\ln\sqrt{x^2+y^2} - \ln|x| + \frac13\arctan\frac{y}{x} = -\ln|x| + C$，$-\ln|x|$ 两边抵消
7) 答案：$\ln\sqrt{x^2+y^2} + \dfrac{1}{3}\arctan\dfrac{y}{x} = C$（等价于 $3\ln\sqrt{x^2+y^2} + \arctan\dfrac{y}{x} = C$）

关键点

提出公因数时负号易丢：$\dfrac{1}{-3-3t^2}$ 提出 $\frac13$ 得 $-\dfrac{1}{3(1+t^2)}$。代回变量时注意 $\ln|x|$ 能否抵消——只有符号正确时才能消去含变量的对数项。

同类易错提醒

  1. 分离变量、提公因式时逐一核对符号，尤其分母带负号时。
  2. 通解中只能把真正的常数并入 $C$；$\ln x^2$、$\ln|x|$ 含变量，除非两边抵消否则不能并入。
  3. 答案碰巧对不等于方法对——养成用初值条件回代验证的习惯。
